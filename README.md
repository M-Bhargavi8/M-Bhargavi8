### [Climate Vision](https://github.com/M-Bhargavi8/ClimateVision): CNN weather classifier
My final-year B.Tech project, revisited. A Keras CNN classifies photos as Cloudy, Rain, Shine or
Sunrise, and a Streamlit app serves the predictions.
`TensorFlow/Keras` `OpenCV` `Streamlit`
- Fixed a softmax/loss mismatch in the original model.
- Evaluated on a held-out test set: **92.9% accuracy**, with per-class metrics and a confusion
  matrix.
- Shrank the model from 156 MB to 5.5 MB with global average pooling.
